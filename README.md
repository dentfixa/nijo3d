# Nijo Castle 2 km — three.js (실사 3D ↔ 파스텔 화풍)

Real-time three.js scene of the area within 2 km of Nijo Castle (二条城), Kyoto.
Modes: 궤도 (orbit) · 드론 (drone) · 걷기 (walk). Style toggle: button / S (orbit) / P (drone, walk).
